# ハガキング（ハガキ並べアプリ）

GitHub Pagesでそのまま公開できる、HTML / CSS / JavaScript の1ファイルWebアプリです。


## 2026-08-19 修正

- A・B・C列ごとに「この列の枚数」を直接指定できる入力欄を追加しました。0〜10枚を数値入力または − / ＋ ボタンで変更できます。
- 縦向き枚数・横向き枚数の入力も残し、合計枚数と連動するようにしました。
- 1段目・2段目の向きは枚数が少ない状態でも設定できるようにし、枚数を増やした際にその指定を使って配置します。
- プレビューでは1段目・2段目を最初から固定段として表示し、3段目以降のみドラッグ対象とする表示を明確化しました。
- 初期化順序の不具合を修正しました。以前は `loadLibrary()` の実行時に、まだ初期化されていない `uid()` を参照して JavaScript が停止し、設定ボタンや各列の入力欄が動作しない状態になっていました。
- ライブラリの読み込みを、関数定義とイベント登録の準備後に行う構造へ変更しました。
- ブラウザ保存が利用できない環境でも、アプリ全体が停止しないように保存処理を保護しました。
- 設定ウインドウ、列数、縦/横枚数、1段目・2段目、ドラッグ並べ替え、フォルダ/シート保存、CSV書き出し/読み込みを再確認しています。

## 現行仕様

- 配置可能領域：788 × 1,837 mm
- 縦向きハガキ＋ネームプレート：100 × 180 mm（横 × 縦）
- 横向きハガキ＋ネームプレート：150 × 130 mm（横 × 縦）
- 1列 / 2列 / 3列に対応
- A・B・C列ごとに合計枚数を0〜10枚で直接指定
- A・B・C列ごとに縦向き / 横向き枚数の内訳も指定
- 1段目・2段目の向きを指定
- 2枚目以降は、その列の1枚目の中央位置に揃えて配置
- 各列の上下余白を自動計算
- 3段目以降のハガキは、配置プレビュー上でドラッグして並べ替え可能
- 並べ替え後は上下余白を自動再計算
- 1段目・2段目はドラッグ不可（固定）

## 保存機能

右上の「設定」から管理します。

- アプリ内にフォルダを作成
- フォルダの中へ複数のシートを保存
- フォルダ名を後から変更
- ファイル名 / シート名を後から変更
- 保存済みシートを開く / 削除
- 以前の `hagaking.sheets` 形式のブラウザ保存データがあれば、新しいフォルダ形式へ自動移行

保存先はブラウザの `localStorage` です。

## CSV

「設定」→「全体をCSV書き出し」では、現在の1シートだけではなく、以下をまとめて1つのCSVへ保存します。

- フォルダ構成
- 各フォルダ内の全シート
- ファイル名 / シート名
- 列数
- 縦 / 横の枚数
- 1段目 / 2段目の向き
- ドラッグ後の並び順
- 寸法表示設定
- 現在開いている状態

同じCSVを読み込むと、フォルダ・シート・並び順を含めて再現します。
旧バージョンの単一シートCSVも読み込み対象にしています。

## 横方向ルール

1枚目に指定位置を適用し、2枚目以降は1枚目の中央線へ揃えます。

### 1列
- 縦：左から 319 mm
- 横：左から 344 mm

### 2列
- 縦：外側余白 180 mm
- 横：外側余白 154 mm
- A列は左端基準、B列は右端基準

### 3列
- A列：縦 100 mm / 横 75 mm を左端から
- B列：縦 344 mm / 横 319 mm を左端から
- C列：縦 100 mm / 横 75 mm を右端から

## GitHub Pagesで公開する方法

1. 新しいGitHubリポジトリを作成
2. `index.html` をリポジトリ直下へアップロード
3. GitHubの `Settings` → `Pages`
4. `Build and deployment` の Source を `Deploy from a branch`
5. Branch を `main` / `(root)` にして保存
6. 発行されたURLへアクセス

Material Symbolsの設定アイコン表示にGoogle Fontsを利用しています。アプリ本体の配置計算・保存・CSV処理には外部APIやサーバーは不要です。
